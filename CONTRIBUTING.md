# Contributing

Official Codex Mobile providers enter through pull requests to this repository. A contribution supplies the standard Codex bundle, shared schema, Android feature implementation, MCP implementation, tests, SBOM inputs, licences, and bounded release metadata required for the capability.

Do not submit embedded user credentials, helper executables, shell adapters, generic command tools, or provider code that bypasses the host's approval, enablement, workspace, deadline, cancellation, and journal boundaries.

Contributions are licensed under `GPL-3.0-or-later`. A dependency under non-GPL terms requires explicit compatibility review; the existing ML Kit permission is limited to the declared Documents OCR closure.
