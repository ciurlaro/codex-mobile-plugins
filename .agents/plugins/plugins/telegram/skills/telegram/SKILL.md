# Telegram

Use the bounded Telegram read, search, and download tools. Authentication is
managed by the active execution provider; Codex Mobile owns it in Settings.

Use send tools only for an explicit user request. A send makes one logical
provider submission and an indeterminate result must never be retried
automatically.
